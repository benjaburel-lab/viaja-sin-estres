2. Información que puede gestionarse

Según el servicio utilizado, el sistema puede gestionar información necesaria para organizar y mostrar un viaje, como destino, fechas, itinerario, actividades, traslados, avisos, documentación e imágenes que el responsable del servicio decida cargar.

El sitio público no incorpora un formulario propio de registro de usuarios ni un sistema de pagos. Las consultas realizadas mediante WhatsApp o correo electrónico se gestionan en los servicios correspondientes.

3. Finalidad

La información se utiliza para brindar y organizar información relacionada con viajes, permitir al cliente consultar su itinerario y documentación, responder consultas y mantener actualizado el contenido del viaje.

4. Portal mediante código

El acceso al portal del viajero se realiza mediante un código incluido en el enlace o código QR correspondiente al viaje. El código funciona como mecanismo de acceso al contenido de ese viaje, por lo que no debe compartirse públicamente cuando la información mostrada sea destinada exclusivamente a los viajeros.

5. Proveedores tecnológicos

El sistema utiliza servicios tecnológicos de terceros para alojar la aplicación, gestionar la base de datos, autenticación y almacenamiento de archivos. Entre ellos se encuentra Supabase. Algunas páginas también pueden cargar librerías desde redes de distribución de contenido.

6. Conservación y eliminación

La información se conserva mientras sea necesaria para la prestación y gestión del viaje o mientras exista una finalidad legítima para mantenerla. Cuando deje de ser necesaria, podrá eliminarse de acuerdo con los procedimientos internos y las obligaciones aplicables.

7. Derechos de las personas

Las personas pueden solicitar información sobre los datos vinculados con ellas y, cuando corresponda, ejercer los derechos de acceso, rectificación, actualización o supresión mediante el contacto indicado en esta página.

8. Seguridad

Se aplican medidas técnicas destinadas a restringir el acceso administrativo y proteger la información almacenada. No obstante, ningún sistema conectado a Internet puede garantizar seguridad absoluta.
